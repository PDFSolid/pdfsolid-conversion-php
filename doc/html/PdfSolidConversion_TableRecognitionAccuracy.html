TableRecognitionAccuracy

PdfSolidConversion\TableRecognitionAccuracy

PdfSolidConversion\TableRecognitionAccuracy

DocumentAI table recognition model profiles used by ConvertOption::$tableRecognitionAccuracy.

Constants

NameValueDescription
HIGH_ACCURACY0Highest accuracy; requires the table_legacy.model extension model.
BALANCED1Balanced profile and default.

Load the requested model with LibraryManager::setDocumentAIModel() before conversion. If the requested accuracy model is not loaded, the conversion still succeeds and tables fall back to rule-based recognition.
