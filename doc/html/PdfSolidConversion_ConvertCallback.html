ConvertCallback

PdfSolidConversion\ConvertCallback

Optional callbacks passed to conversion methods. Callbacks execute synchronously on the calling thread; unset properties use the built-in behavior. Keep the callback object alive until conversion returns.

onProgress reports the current and total pages; return true from onCancel to request cancellation. Configure custom AI callbacks in pairs (an incomplete pair raises an argument error): onOcr/onOcrResult, onLayout/onLayoutResult, or onTable/onTableResult. The trigger receives the page image path and returns true when handled; the matching result callback returns the SDK-defined JSON result for that image, or null on failure. See the developer guide and delivered samples/callback_demo.php for schemas and examples.

onProgress: function (int $currentPage, int $totalPage): void
onCancel: function (): bool
onOcr: function (string $imagePath): bool
onOcrResult: function (): string
onLayout: function (string $imagePath): bool
onLayoutResult: function (): string
onTable: function (string $imagePath): bool
onTableResult: function (): string

Callback exceptions request cancellation and are rethrown after native conversion returns. The binding retains result buffers for the synchronous call and releases them afterwards.
