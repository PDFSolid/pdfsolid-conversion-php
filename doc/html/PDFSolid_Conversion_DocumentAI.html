PDFSolid\Conversion\DocumentAI

PDFSolid\Conversion\DocumentAI

Thin wrapper over the document-AI C entrypoints. Each method returns plain PHP arrays/values and takes care of releasing the underlying native buffers via the corresponding CPDF_*Release function.

Mirrors the document_ai module of the Python SDK.

Source: pdfsolid_sdk/php/src/DocumentAI.php
