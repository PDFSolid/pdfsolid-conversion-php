PDFSolid Conversion SDK for PHP 1.2.0 - Linux x86_64
Packaged: 2026-09-17

Native SDK, DocumentAI, ONNX Runtime and OpenCV come from out/release.
The model comes from PDFSolid_Conversion_linux_c_1_2_0/resource/models/documentai.model.

Updated PHP FFI declarations and rebuilt the C bridge against the current C API.
CConvertOption grew from 568 to 576 bytes on Linux x86_64:
  enable_document_orientation_classification (offset 568)
  enable_document_dewarp (offset 569)
The current PHP API also exposes the corresponding option properties and
license concurrency/page-limit/quota and unsupported-feature error codes.

The bridge uses distinct pdfsolid_php_convert_* entry points for the PHP
pointer-to-structure interface, preserving the SDK's by-value C ABI.
The normal PHP conversion methods retain their names and callback arguments.

The direct conversion demo now explicitly loads and releases the packaged AI
model.

Use the Conversion\ PHP namespace and samples/pdfsolidphp launcher.
samples/compdfphp remains available as an alias.
Native bridge source and matching C headers are included in native/.
